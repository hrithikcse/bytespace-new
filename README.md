# ByteSpace New

A modern landing page for ByteSpace, built with Next.js 14 and Tailwind CSS.

Live demo: https://bytespace-new-alpha.vercel.app

## Features
- Hero section
- Courses section
- Growth section
- Testimonials section
- Footer
- Bonus: Login and Signup pages

## Tech Stack
- Next.js 14
- React
- Tailwind CSS

## Project Structure
- app/ : pages and routes
- components/ : reusable UI components
- public/ : static assets

## Getting Started
npm install
npm run dev

Open http://localhost:3000 in your browser.
